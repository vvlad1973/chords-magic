## 1. Требования

### Системные зависимости

| Инструмент | Версия | Зачем |
|---|---|---|
| Python | ≥ 3.10 | основной рантайм |
| ffmpeg | любая свежая | извлечение аудио из видео, нормализация |
| CUDA (опционально) | ≥ 11.8 | ускорение demucs на GPU |

Установка ffmpeg:
```bash
# Ubuntu / Debian
sudo apt install ffmpeg

# macOS
brew install ffmpeg

# Windows — скачать с https://ffmpeg.org/download.html и добавить в PATH
```

### Python-пакеты

```bash
pip install demucs basic-pitch mido PyGuitarPro numpy
```

> **Примечание про numpy:** basic-pitch/tensorflow требует numpy < 2.0.
> Если у вас numpy 2.x — он будет автоматически понижен при установке.
> Это не влияет на работу скрипта.

## 2. Установка

```bash
git clone https://github.com/vvlad1973/chords-magic
cd chords-magic
pip install -r requirements.txt
```

Первый запуск demucs автоматически скачает модель `htdemucs_6s` (~300 МБ).
Модель кешируется в `~/.cache/torch/hub/`.

## 3. Быстрый старт

```bash
# Из видео (концерт, YouTube-запись)
python transcribe.py concert.mp4

# Из аудио
python transcribe.py solo.wav

# Результат: solo.gp5 в той же папке
```

Открыть `.gp5` можно в **Guitar Pro 5/6/7/8** или бесплатно в **TuxGuitar**.

## 4. Входные данные

### Поддерживаемые форматы

| Тип | Форматы |
|---|---|
| Аудио | `wav`, `mp3`, `flac`, `ogg`, `m4a`, `aiff` |
| Видео | `mp4`, `mkv`, `avi`, `mov`, `webm`, `m4v`, `flv`, `wmv`, `ts`, `mts`, `vob` |

Скрипт определяет тип файла по расширению.
Из видео автоматически извлекается аудиодорожка через ffmpeg.

### Рекомендации к исходнику

Чем лучше запись — тем точнее результат:

| Условие | Влияние |
|---|---|
| Чистая гитара без вокала и баса | Можно пропустить demucs (`--skip-demucs`) |
| Стерео vs моно | Без разницы — скрипт конвертирует в моно |
| Bitrate | 128 kbps достаточно; выше — лучше |
| Громкость | Нормализуется автоматически |
| Реверб/эффекты | Снижают точность basic-pitch |

## 5. Как работает пайплайн

```
Видео/Аудио
    │
    ▼ [Шаг 0] ffmpeg — только если видео
    │   Извлечение аудиодорожки
    │
    ▼ [Шаг 1] ffmpeg — предобработка
    │   • Моно (1 канал)
    │   • 44 100 Hz (оптимум для basic-pitch)
    │   • Нормализация громкости (EBU R128 loudnorm)
    │
    ▼ [Шаг 2] demucs htdemucs_6s — разделение стемов
    │   Входит: микс (вокал + гитара + бас + ударные + пиано + other)
    │   Выходит: guitar.wav — изолированный гитарный стем
    │
    ▼ [Шаг 3] basic-pitch (Spotify) — транскрипция
    │   Входит: guitar.wav
    │   Выходит: MIDI-файл со всеми детектированными нотами
    │   Нейросеть: ICASSP 2022 model (onsets + frames)
    │
    ▼ [Шаг 4] MIDI cleanup — очистка
    │   • Удаление слишком коротких нот (артефакты атаки)
    │   • Квантизация к ритмической сетке (16th note по умолчанию)
    │   • Удаление дублирующихся нот той же высоты
    │
    ▼ [Шаг 5] Fretboard DP — расстановка по грифу
    │   Для каждой ноты находятся все возможные позиции (струна, лад)
    │   Алгоритм Витерби минимизирует суммарное перемещение руки:
    │     cost = |Δлад| + 0.5·|Δструна| + штраф_за_смену_позиции
    │   Прыжок > 4 ладов = смена руки = дополнительный штраф ×2
    │
    ▼ [Шаг 6] PyGuitarPro — запись .gp5
        Ноты → такты → треки → Guitar Pro 5
```

## 6. Все параметры CLI

```
python transcribe.py [OPTIONS] INPUT
```

### Основные

| Параметр | По умолчанию | Описание |
|---|---|---|
| `INPUT` | — | Входной файл (аудио или видео) |
| `-o / --output` | `<input>.gp5` | Путь к выходному файлу |
| `--bpm` | авто | Принудительно задать BPM |
| `--work-dir` | `./work` | Папка для всех промежуточных файлов |
| `--stems-dir` | `<work>/stems` | Папка для стемов demucs |
| `--midi-dir` | `<work>/midi` | Папка для MIDI-файлов |

### Управление шагами пайплайна

| Параметр | Описание |
|---|---|
| `--skip-demucs` | Пропустить разделение стемов (вход уже — чистая гитара) |
| `--skip-preprocess` | Пропустить ffmpeg-нормализацию (вход уже 44100 Hz моно) |

### Настройка basic-pitch

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--onset THRESH` | `0.5` | Порог детектирования начала ноты (0–1) |
| `--frame THRESH` | `0.3` | Порог детектирования длительности ноты (0–1) |
| `--min-note-ms MS` | `60` | Минимальная длительность ноты в мс |

### Очистка MIDI

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--quantize N` | `16` | Квантизация к N-й ноте (4=четверть, 8, 16, 32, 0=выкл) |
| `--no-dedup` | выкл | Отключить удаление дублирующихся нот |

## 7. Настройка качества

### basic-pitch пороги

Два ключевых параметра управляют балансом «мало нот / много шума»:

```
Меньше нот ←────────────────────────────────────── Больше нот
  onset=0.7   onset=0.5 (default)   onset=0.3
  frame=0.5   frame=0.3 (default)   frame=0.15
```

**Когда повышать пороги** (↑ onset, ↑ frame):
- В транскрипции слишком много лишних нот
- Много кратких артефактов между реальными нотами
- Запись с сильным реверберацией или шумом

**Когда понижать пороги** (↓ onset, ↓ frame):
- Пропускаются тихие или быстрые ноты
- Легато / hammer-on ноты не распознаются
- Чистая запись без фоновых инструментов

**Рекомендуемые наборы для разных типов записи:**

```bash
# Студийная запись — агрессивная очистка
--onset 0.6 --frame 0.4 --min-note-ms 80

# Live / с реверберацией
--onset 0.5 --frame 0.3 --min-note-ms 60   # defaults

# Чистая сольная гитара без эффектов
--onset 0.35 --frame 0.2 --min-note-ms 40
```

### Квантизация

```bash
--quantize 32   # Точнее ритм, подходит для быстрых соло
--quantize 16   # Сбалансировано (default)
--quantize 8    # Если соло размеренное, без мелких длительностей
--quantize 0    # Без квантизации — сырой ритм из MIDI
```

### BPM

Если ритм в Guitar Pro выглядит неправильно (ноты не попадают в такты):
1. Определите BPM вручную (tap tempo, DAW, или `--quantize 0` + анализ MIDI)
2. Передайте: `--bpm 132`

## 8. Типичные сценарии

### Сценарий 1: Видео с YouTube

```bash
# Скачать видео
yt-dlp -f "bestvideo+bestaudio" "https://youtube.com/watch?v=..." -o solo.mp4

# Транскрипция
python transcribe.py solo.mp4 --onset 0.45 --bpm 120
```

### Сценарий 2: Студийный трек (mp3)

```bash
python transcribe.py track.mp3 \
  --onset 0.55 --frame 0.35 \
  --min-note-ms 70 \
  --quantize 16
```

### Сценарий 3: Чистая гитара (DI запись без эффектов)

```bash
python transcribe.py di_guitar.wav \
  --skip-demucs \
  --onset 0.3 --frame 0.2 \
  --min-note-ms 40 \
  --quantize 32
```

### Сценарий 4: Live-концерт (много шума)

```bash
python transcribe.py concert.mkv \
  --onset 0.6 --frame 0.4 \
  --min-note-ms 100 \
  --quantize 8
```

### Сценарий 5: Отладка — сохранить промежуточный MIDI

```bash
python transcribe.py solo.wav --work-dir ./debug_output
# Проверить: ./debug_output/midi/*.mid в любом MIDI-редакторе
# Например: open ./debug_output/midi/guitar_norm_basic_pitch.mid
```

## 9. Промежуточные файлы

Все создаются в `./work/` (или `--work-dir`):

```
work/
├── solo_audio.wav          # (только для видео) извлечённая аудиодорожка
├── solo_norm.wav           # нормализованный аудио (44100 Hz, моно)
├── stems/
│   └── htdemucs_6s/
│       └── solo_norm/
│           ├── guitar.wav  # ← гитарный стем (основной)
│           ├── vocals.wav
│           ├── bass.wav
│           ├── drums.wav
│           ├── piano.wav
│           └── other.wav
└── midi/
    └── guitar_norm_basic_pitch.mid   # MIDI до очистки
```

> Промежуточные файлы не удаляются автоматически.
> При повторном запуске с теми же именами — перезаписываются.

## 10. Устранение проблем

### `ffmpeg: command not found`

```bash
# Проверить установку
ffmpeg -version

# Ubuntu
sudo apt install ffmpeg

# macOS
brew install ffmpeg
```

### `Expected guitar stem at ... guitar.wav`

demucs не создал стем. Причины:
- Модель `htdemucs_6s` ещё не скачана — запустите снова, скачается автоматически
- Входной файл повреждён или неподдерживаемого формата
- Недостаточно RAM (htdemucs_6s требует ~4 ГБ)

Проверить вручную:
```bash
python -m demucs -n htdemucs_6s -o ./work/stems audio.wav
```

### `basic-pitch produced no MIDI file`

- Проверьте, что `guitar.wav` не пустой и не тишина
- Попробуйте понизить пороги: `--onset 0.3 --frame 0.2`
- Проверьте вручную:
```bash
python -c "
from basic_pitch.inference import predict_and_save
from basic_pitch import ICASSP_2022_MODEL_PATH
predict_and_save(['guitar.wav'], '.', save_midi=True,
    model_or_model_path=ICASSP_2022_MODEL_PATH)
"
```

### Результат содержит слишком много нот / шум

```bash
--onset 0.65 --frame 0.45 --min-note-ms 100
```

### Ноты не попадают в такты (всё сбито)

1. Задайте BPM вручную: `--bpm 124`
2. Попробуйте `--quantize 0` и откройте MIDI в редакторе чтобы узнать реальный BPM

### Медленная работа (нет GPU)

demucs — самый медленный шаг. На CPU ~2–5 минут на минуту аудио.

Ускорение:
```bash
# Если есть CUDA GPU:
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
# Demucs автоматически использует GPU если доступен
```

### `numpy` конфликт версий

Ошибка типа `RuntimeError: numpy version incompatible`.
```bash
pip install "numpy>=1.21,<2.0"
```

## 11. Ограничения

| Аспект | Ограничение |
|---|---|
| Полифония | basic-pitch хорошо справляется с аккордами, но сложные чорды снижают точность |
| Бенды / вибрато | Не распознаются и не записываются в GP |
| Hammer-on / pull-off | Технически в MIDI присутствуют, но в GP не помечаются |
| Слайды | Не помечаются |
| Темп | Предполагается постоянный BPM на всё произведение |
| Строй | Только стандартный EADGBE; drop D / open tunings требуют правки `STANDARD_TUNING` |
| Длина | Нет ограничений, но >10 мин на CPU займёт ~20–40 мин |

### Настройка нестандартного строя

В начале `transcribe.py`, строка `STANDARD_TUNING`:
```python
# Drop D
STANDARD_TUNING = [64, 59, 55, 50, 45, 38]  # E4 B3 G3 D3 A2 D2

# Open G
STANDARD_TUNING = [62, 59, 55, 50, 47, 43]  # D4 B3 G3 D3 G2 G2

# Half-step down (Eb)
STANDARD_TUNING = [63, 58, 54, 49, 44, 39]
```
